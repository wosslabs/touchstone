# Changelog

All notable changes to this project are documented in this file.

## 0.11.1 — early beta

Published on npm as `@wosslabs/touchstone`.

- CLI (`init`, `check`, and related commands), GitHub Action outer-loop checks,
  agent skills/hook, and multi-language examples.
- Community packaging: `LICENSE` (MIT), `CODE_OF_CONDUCT.md`, `SECURITY.md`,
  `CONTRIBUTING.md`, issue/PR templates, Dependabot.

### Known limits

- Early beta: the Action has not been shown on a real application's own pull
  requests, and there is no external-user pilot yet. See
  [docs/project-status.md](docs/project-status.md).
